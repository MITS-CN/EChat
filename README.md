# Echat

Echat 是一个为 Minecraft 打造的**跨服即时通讯系统**，由一个自研模组客户端和一个独立聊天服务端组成。
它把"聊天"从 Minecraft 游戏逻辑里剥离出来，做成可独立部署的服务，让不同服务器、不同世界的玩家
能够在同一个频道里交流，而不必依赖代理层、Bukkit 插件或原版服务器的内置聊天。

## 组成

| 组件 | 语言 / 技术 | 说明 |
| :--- | :--- | :--- |
| **客户端（Echat Mod）** | Java · Minecraft 模组 | 玩家在游戏内通过 `/Echat ...` 命令使用全部功能：添加服务器、注册账号、连接他人、收发消息、申请 OP 等。客户端只负责命令交互与界面展示，不承载业务状态。 |
| **服务端（Echat Server）** | Rust · Tokio · Axum(WebSocket) · SQLite | 独立部署的聊天服务。管理用户注册、会话状态、服务器地址簿、跨服消息转发与封禁名单。默认监听 `0.0.0.0:1145`，WebSocket 端点 `/echat`。 |

两者之间用 **WebSocket + JSON** 通信：客户端发送纯文本命令（如 `/Echat server list`），
服务端以结构化 JSON 响应与事件推送，协议简单、可读、易调试。

## 核心能力

- **跨服互联**：客户端可添加多个 Echat 服务器地址，一键连接在线服务器，消息自动汇聚到同一频道
- **账户体系**：两阶段注册（名称 + 密码），Argon2 哈希存储，注册名称仅限字母数字下划线
- **会话隔离**：注册状态绑定在当前 WebSocket 会话内，临时会话退出即丢弃未完成注册
- **权限管理**：客户端隐藏命令 `/Echat OP Login` 三重校验提权；服务端支持 kick / ban / ban-ip / pardon
- **零运维部署**：服务端单二进制 + SQLite 单文件，无外部依赖，控制台内置管理命令
- **轻量接入**：客户端模组用 `Java-WebSocket` 一行代码即可建立连接，无需处理 MC 协议细节

## 为什么不用现成方案

Minecraft 的跨服聊天通常依赖 BungeeCord/Velocity 代理或各服自建插件，部署复杂且绑定服务端版本。
Echat 走另一条路：**聊天与游戏解耦**，服务端不感知方块、实体、世界，只处理消息与会话；
客户端只作为命令入口。这让整个系统可以独立演进，不受 Minecraft 版本升级影响。
